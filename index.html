About This Project

3D Warehouse Packing Optimizer

This is an educational tool demonstrating the 3D Bin Packing Problem, a variant of the NP-hard 3D Knapsack problem. The tool uses a greedy heuristic approach to approximate optimal packing solutions.

Algorithm Details

  • Strategy: Greedy approach based on value-to-volume ratio
  • Placement: Best-fit decreasing with 3D spatial tracking
  • Rotation: Optional — tries all 6 orientations per item
  • Collision: Full 3D overlap detection ensures valid placements

Technologies Used

  • HTML5, CSS3, Vanilla JavaScript
  • Three.js for 3D WebGL visualization
  • Greedy heuristic algorithm

How to Use

  1. Set warehouse dimensions
  2. Add items with length, width, height, and value
  3. Toggle rotation and animation options
  4. Click "Optimize Packing" to run the algorithm
  5. View results in the 3D viewer and results table
