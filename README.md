# Warehouse Packing Optimizer

## Description
This project optimizes packing items inside a warehouse using a greedy algorithm.

## Technologies Used
- HTML5, CSS3, JavaScript
- Three.js (for 3D visualization)

## How to Use
1. Enter warehouse dimensions
2. Add items with size and value
3. Click "Optimize Packing"
4. View results in 3D and table

## Features
- 3D visualization
- Greedy optimization
- Rotation support
